# Exercise 1 — First Code and Binary Representation

Starter files and instructions for Exercise 1 in Introduction to Computer
Science (89110), Department of Computer Science and Artificial Intelligence,
Bar-Ilan University.

Read `ex1.pdf`, then complete and submit both source files:

- `ex1-digits.c`
- `ex1-matrix.c`

The complete interaction appears as an appendix in `ex1.pdf`, with each input
shown in blue directly after the prompt that requests it.

The `tests` folder contains ready-to-use input and expected-output files. See
the handout for the exact `<`, `>`, and `diff` commands.

Submit one ZIP whose top level contains exactly those two files through the
[course submission system](https://submit.cs.biu.ac.il). Do not include the
library, executables, build products, folders, or other files.

## Reference executables

The `executables` directory contains reference programs for both parts on
macOS, Linux, and Windows. Each platform folder contains:

- `ex1-digits-simulator` (or `.exe` on Windows)
- `ex1-matrix-simulator` (or `.exe` on Windows)
- `ex1-digits-arduino.hex`
- `ex1-matrix-arduino.hex`

These files demonstrate required behavior and are not part of the submission.

Work on a local clone. You cannot push changes to this course repository. If
you keep your work in your own GitHub repository, that repository must remain
private. Do not make exercise solutions publicly accessible.
